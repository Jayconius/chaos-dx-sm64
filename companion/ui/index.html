Chaos Companion

Twitch

Not connected
Reads your chat as a guest: no login or password needed. Chatters vote by typing a number; each person's first vote counts.

OBS

In game, the host sets Chaos to Source 3 (Twitch) in the mod menu, or types /chaos twitch. Co-hosts: the host types /chaos cohost <player name>; the co-host runs this app with their own channel. Add ?theme=mario64 (or classic, transparent, minimal) to the overlay URL to force a style for one scene; a URL with ?theme= ignores the style picked here. Add ?preview=1 to see a sample vote in OBS while you set it up.
